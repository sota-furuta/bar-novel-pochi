# BAR NOVEL — pochi edition

BAR NOVEL（伊勢原）のホームページ、ポチ版です。
`sota-furuta/bar-novel-bootstrap` をベースに、ポチが自由に作り直した別デザイン版。

## デザイン

- テーマ: 深いエスプレッソブラウン × コパー（銅色）のスピークイージー風
- モバイルファースト（下部固定のクイックアクションバー付き）
- ヒーローはカウンター写真＋ゆっくりズームアウト、セクションはスクロールでフェードイン
- メニューは DRINK / FOOD タブ切り替え

## 構成

- `index.html` / `style.css` / `script.js` のみ（ビルド不要、素の HTML/CSS/JS）
- 写真は `bar-novel-bootstrap` リポジトリの IMG_8580〜8584 を参照

## 公開

GitHub Pages を有効化すると `https://sota-furuta.github.io/bar-novel-pochi/` で公開されます
（Settings → Pages → Source: `main` / root）。
